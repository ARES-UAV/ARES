# Hardware

This directory contains the hardware design and documentation
for the physical ARES UAV prototype.

## Planned Components

### UAV Platform

- Frame
- Motors
- ESCs
- Propellers
- Flight controller
- Battery
- Power management

### Computing

- Companion computer
- Storage
- Communication/telemetry hardware

### Sensors

- RGB camera
- GPS
- IMU
- Barometer
- Optional thermal camera
- Optional additional sensors

## Planned Work

- Hardware selection
- Bill of Materials (BOM)
- Electrical architecture
- Wiring diagrams
- Camera mounting
- CAD design
- Power budget
- Payload estimation
- Flight testing

## Important

Hardware implementation will begin after the core software
and simulation prototype has been validated.
