# AI

This directory contains the artificial intelligence and computer
vision components of ARES.

## Planned Components

- Human/survivor detection
- Object tracking
- RGB-based detection
- Thermal-based detection
- RGB-thermal sensor fusion
- Survivor state/priority estimation
- Model evaluation and inference
