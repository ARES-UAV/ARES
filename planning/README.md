# Planning

This directory contains the search, mission planning, and
decision-making algorithms used by ARES.

## Planned Components

### Search Strategies

- Random search
- Grid/lawn-mower search
- Nearest-target search
- Adaptive search

### Adaptive Search

ARES will dynamically select the next search region based on
information such as:

- Survivor probability
- Detection confidence
- Search uncertainty
- Survivor priority
- Distance
- Estimated energy cost
- Previously searched regions

### Risk Model

The system will investigate risk-aware survivor prioritization
using available visual and contextual information.

### Energy-Aware Planning

The planner will consider remaining battery/energy when selecting
future search regions.

## Planned Research Comparison

Baseline algorithms will be compared against the proposed
ARES adaptive planning approach.
