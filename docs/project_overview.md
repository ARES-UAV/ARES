# ARES — Project Overview

## Full Name

Adaptive Rescue and Exploration System

## Overview

ARES is an AI-assisted autonomous UAV system designed for
disaster-zone search and rescue.

The system combines computer vision, survivor localization,
risk-aware prioritization, adaptive search planning, and
energy-aware mission planning.

## Core Idea

Instead of following a fixed search pattern, ARES dynamically
determines where the UAV should search next based on information
collected during the mission.

## Core Components

1. AI-based survivor detection
2. Object tracking
3. Survivor localization
4. Risk/priority estimation
5. Adaptive search planning
6. Energy-aware mission planning
7. Ground station
8. UAV platform

## Current Phase

Research and software prototyping.
